# Gentleman's Gentleman

> 灵感来自英国管家——**你不用再写那条会照醒你的自动化**。

用快速判别模型（首个 Provider：Jev）读传感器与外部事实，判断屋子当前**是不是**你说的那个状态，再决定要不要动手。
链路：触发 → 读数快照 → 上下文 → 模型判断 → 阈值 → 执行动作 → 全程留痕。

## 这个仓库是什么

**内测发布仓**：只放"装到你 Home Assistant 上的那一份"——折叠好的集成目录、`hacs.json` 与发布用的 zip 资产。
架构决策、领域模型推导与开发过程都在本地开发仓，不在这个仓里；等产品能跑了再决定要不要一并公开。

## 已知边界（现在就说清楚）

- **需要一个 Jev API Key**（`api.typesafe.ai`）。Home Assistant 把集成配置存在本地明文文件里，这是 HA 平台的既有机制、我们无法改变；密钥不会出现在日志、留痕或诊断信息里。
- **模型会判错**。执行动作前有一道确定性的动作门：允许实体白名单、互斥组、防抖冷却，以及模型不可达时的安全回退——AI 从不直接控制设备。
- **判断能力依赖你手上的传感器**。没有某个传感器不是缺陷，是这个产品存在的前提；但传感器越少，判断的把握度越低。
- 本版本是**内测**，不承诺兼容后续版本的配置格式。
